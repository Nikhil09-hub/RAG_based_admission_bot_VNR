# Project Overview

| Topic | Summary |
|---|---|
| Purpose | Admissions assistant for VNRVJIET with chatbot UI, website embed, cutoff lookup, and knowledge-base Q&A. |
| Target users | Prospective students, parents, admission staff, and website visitors. |
| Core functionality | Admissions answers, cutoff ranks, eligibility checks, multilingual support, document guidance, contact capture, admin review. |
| Key workflows | Chat request -> language resolution -> guided flow/classifier -> cutoff engine or RAG -> formatted response. |

Important scope rule:
- The assistant is for VNRVJIET only and should refuse other colleges or comparison-style requests.
